## 사용법

### 로그 분석

1. `harness.log`를 프로젝트 루트나 적절한 위치에 놓습니다.  
2. 다음 명령을 실행하여 로그를 분석합니다:

```bash
python log_analyzer.py path/to/harness.log --json-output categorized.json
```

3. 출력되는 요약을 확인하고, 상세 내용을 `error_report.md`에 반영합니다.

### 프롬프트 작성

- `prompt_v1.md`와 `prompt_v2.md`는 각각 기본과 개선된 프롬프트를 정의합니다.  
- 실험을 통해 v2가 v1보다 나은 성능을 보여야 합니다. 개선 사항이나 차이점은 아래 분석에 기록하십시오.

### A/B 테스트

1. 에이전트 또는 응용프로그램에 프롬프트를 적용할 수 있도록 `run_prompt` 함수를 구현합니다.  
2. `python ab_test.py --run-count 5 --output ab_results.json`을 실행하면 두 버전의 프롬프트를 여러 번 실행하고 결과를 `ab_results.json` 파일에 저장합니다.
3. 결과 JSON을 분석해 어느 버전이 더 안정적이고 빠른지 `README.md`에 요약하세요.

## 분석 및 토의

테스트 결과를 토대로 프롬프트 개선 사항을 평가합니다. 예를 들어, v2는 오류를 카테고리별로 분석하고 수정 계획을 문서화하도록 지침을 추가하여 반복 오류를 줄이는 데 도움이 됩니다. 성능 차이가 미미하다면, 새로운 지시문이 실제로 필요한지 재검토하고 v3를 설계해보세요.
