# Lab 06 Prompt v1

> **Note**  
> 본 파일은 v1 프롬프트의 기본 버전을 제공합니다. 프롬프트 작성 시 명확하고 간결한 지시문을 포함해야 하며, 성공적인 실습 수행을 위해 필요한 모든 단계가 서술되어야 합니다.

## 목표

주어진 코드 베이스를 수정하여 모든 테스트가 통과하도록 하세요. 아래 지시사항을 따르며 불필요한 변경 없이 문제를 해결하는 것이 중요합니다.

## 지시 사항

1. 저장소를 초기화한 뒤 `pytest tests/ -q --tb=short` 명령어를 실행하여 실패하는 테스트를 확인하십시오.
2. 실패한 테스트에 해당하는 모듈을 찾아 수정하세요.  
   - **코드 수정 시:** 최소한의 변경으로 테스트를 통과하도록 하세요.  
   - **새로운 함수나 모듈 추가가 필요한 경우:** 명확한 이유를 주석으로 남기고 구현합니다.
3. 모든 수정 후 다시 `pytest`를 실행하여 테스트가 통과하는지 확인합니다.
4. 문제 해결 과정에서 작성한 간단한 노트나 개선 사항은 `README.md`에 기록하세요.
5. 모든 테스트를 통과하면 `DONE.md` 파일을 생성하고, 그 안에 `all tests passed`라는 문구를 적습니다.

## 참고 사항

* 커밋 메시지는 **규칙**에 따라 `type: 설명` 형식을 사용합니다. 예: `feat: implement feature X`.
* 코드 예시는 반드시 실행 가능한 형태로 작성하고, 한국어 주석을 허용합니다.
* 마크다운 문법과 맞춤법을 준수합니다.
