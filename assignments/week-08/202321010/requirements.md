# 프로젝트 요구사항: 간단한 계산기

## 목적
기본적인 산술 연산을 수행하는 계산기 클래스를 구현한다.

## 기능 요구사항
1. **덧셈 (add)**: 두 숫자를 더한다
2. **뺄셈 (subtract)**: 첫 번째 숫자에서 두 번째 숫자를 뺀다
3. **곱셈 (multiply)**: 두 숫자를 곱한다
4. **나눗셈 (divide)**: 첫 번째 숫자를 두 번째 숫자로 나눈다

## 비기능 요구사항
1. **예외 처리**: 0으로 나누는 경우 적절한 예외를 발생시킨다
2. **테스트 커버리지**: 모든 기능에 대한 단위 테스트를 작성한다
3. **코드 품질**: PEP 8 스타일 가이드를 준수한다

## 제약사항
- Python 3.8 이상 사용
- 외부 라이브러리 사용 최소화 (pytest 제외)

## 성공 기준
- 모든 단위 테스트 통과
- 0으로 나누기 예외 처리 구현
- QA 에이전트 리뷰 통과 (모든 점수 4점 이상)
